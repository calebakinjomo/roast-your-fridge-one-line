One line roasting a fridge, written for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty. The program writes the line to `/output/entry.txt` — a single line of at most 200 characters, funny to someone who has never met the appliance.

> The butter compartment in my fridge door is the warmest spot in the whole appliance, which is fitting, because it's where my willpower goes to melt.

The joke turns on a real, specific fridge detail — the butter compartment in the door is famously the warmest spot in the whole appliance — and pays off with a double meaning in the last few words: butter melts there, and so does the owner's willpower.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (148 characters, one line, no trailing newline) after validating it against the gate: UTF-8 text, 1–200 characters, not only whitespace, a single line.
